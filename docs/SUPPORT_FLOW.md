# YukCep Support Flow

## Channels
- In-app Help Center screen
- Email: `support@yukcep.app`
- Abuse/Security: in-app `İlanı Raporla`

## Ticket Priorities
- `P1`: login failure, post/bid blocked globally
- `P2`: role/feed inconsistency, notification delays
- `P3`: UI issue, copy, non-blocking bug

## Triage Template
1. User role (`driver/employer`)
2. Action attempted
3. Timestamp (UTC)
4. Runtime event code(s)
5. Browser/device

## FAQ Baseline
- How to switch role (driver/employer)?
- Why can’t I see my listing immediately?
- Why did my bid fail?
- How to report suspicious listings?
- How to hide phone number visibility?

## Response SLA
- P1: first response <= 15 min
- P2: first response <= 2 h
- P3: first response <= 1 business day
